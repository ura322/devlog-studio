Devlog Studio

Devlog Studio is my personal tool. I run it on my own computer to manage my own YouTube channels: it uploads video titles, descriptions, subtitles and thumbnails, schedules videos and reads the channels' analytics. It has no other users.

Privacy policy

  • Devlog Studio uses YouTube API Services. It works only with channels I own, and only after I sign in with my Google account.
  • The data it reads (video details, comments, analytics) stays on my computer. It is never sold, shared with anyone or used for advertising.
  • Sign-in tokens are stored only on that computer. Deleting them, or revoking access on the Google security settings page, removes Devlog Studio's access.
  • Devlog Studio uses no cookies or trackers.

By using YouTube API Services you agree to the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.
